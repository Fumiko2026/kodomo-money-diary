## 2. 画面のつながり

```
 とうろく(S1) ⇄ ログイン(S2)
        │ ログイン後
        ▼
 ┌──────────── 下のタブ(いつも表示) ────────────┐
 │ ホーム(S3) │ きろく(S5) │ まとめ(S6) │ ほしい(S7) │ もっと │
 └────────────────────────────────────────────────┘
      │                                      │
      ▼ 「きろくする」ボタン(ホームと一覧)       ▼ 「もっと」
  きろくする(S4)                          項目(S8) / せってい(S9)
```

- 下のタブは 5 つ(ホーム、きろく、まとめ、ほしい、もっと)。画面の下に固定し、押しやすい大きさ(高さ 56px)にする。
- 「きろくする」の大きなボタンは、ホームと一覧の右下に置く(毎日使う操作のため、いちばん押しやすい所へ)。
- ログインしていないときは、S1 と S2 だけが見られる。

## 3. 言葉の決まり(漢字は小学 4 年生まで)

| 要件定義書の言葉 | 画面の言葉 | 理由 |
|---|---|---|
| 収入 | もらった | 「収」は 6 年生の漢字 |
| 支出 | つかった | 「支」は 5 年生の漢字 |
| 残額 | 👛 さいふ | 「額」は 5 年生の漢字。「いまのお金」は、貯金もお金なので混ざる。絵と言葉を、すべての画面で同じにそろえる |
| 貯金額 | 🐷 貯金 | 「貯」は 4 年生の漢字なので、そのまま使える |
| 項目 | しゅるい | 「項」は 6 年生の漢字 |
| 目標金額 | ほしい金がく | 「額」は 5 年生の漢字のため |
| 計画 | 計画(けいかく) | 「計」「画」は 2 年生の漢字 |
| お小遣い | おこづかい | 「遣」は常用漢字だが、小学校では習わない |
| お年玉 | お年玉 | 「年」1 年、「玉」1 年 |

**絵の決まり(0.2 で追加)**: 「貯金」を表す絵は、ぶたの絵文字(🐷)ではなく、コインの入れ口がある**貯金箱の絵**(`frontend/src/components/PiggyIcon.vue`)にそろえる。表紙、ホーム、きろくする、一覧、まとめで、同じ絵を使う。このあとのスケッチにある 🐷 は、この絵に読みかえる。さいふは、そのまま 👛。

迷ったら、ひらがなにする。むずかしい言葉に、ふりがなをつけて残すことは、しない(画面がうるさくなるため)。

## 4. 各画面のスケッチ

### S3 ホーム

```
┌──────────────────────────────┐
│ こどもマネー日記       ◯◯さん │
├──────────────────────────────┤
│ ┌────────┐ ┌────────┐       │
│ │ 👛 さいふ │ │ 🐷 貯金   │       │
│ │ 1,100円  │ │   300円  │       │
│ └────────┘ └────────┘       │
│                              │
│ 11月のまとめ                  │
│  ＋ もらった   500円          │
│  − つかった   100円          │
│                              │
│ ほしいもの                    │
│  ゲームソフト                 │
│  [■■■□□□□□] 300 / 5,000円  │
│  あと 6 か月くらい            │
│                              │
│ さいきんの きろく             │
│  11/12 ＋ おこづかい   500円  │
│  11/12 − おやつ       100円  │
│  11/13 🐷 貯金へ       300円  │
│                    [ きろくする ] │
├──────────────────────────────┤
│ ホーム きろく まとめ ほしい もっと │
└──────────────────────────────┘
```

- さいふと貯金は、同じ大きさのカードにして、並べて表示する(分けて表示する決定に合わせる)。
- ほしいものが 0 件のときは、「ほしいものを入れてみよう」のボタンを出す。

### S4 きろくする

```
┌──────────────────────────────┐
│ ←  きろくする                │
├──────────────────────────────┤
│ なにを した?                 │
│ [＋もらった][−つかった]        │
│ [🐷貯金へ入れた][👛貯金からだした] │
│                              │
│ ひづけ    [ 2026/11/15 ]  ← 今日が自動で入る。おして えらびなおせる │
│ 金がく    [        円 ]      │
│                              │
│ ▼ 「もらった」のとき          │
│ しゅるい  (●)おこづかい (○)お年玉 │
│                              │
│ ▼ 「つかった」のとき          │
│ しゅるい  [おやつ][おもちゃ]   │
│           [ゲーム][＋あたらしく作る] │
│                              │
│ メモ      [              ]   │
│                              │
│          [ きろくする ]       │
└──────────────────────────────┘
```

- 4 つの「なにを した?」で、入力する欄が変わる。
  - **もらった**: 金額、おこづかい / お年玉、メモ
  - **つかった**: 金額、しゅるい(項目)、メモ
  - **貯金へ入れた**: 金額、メモ(さいふ → 貯金)
  - **貯金からだした**: 金額、メモ(貯金 → さいふ)
- 項目の「貯金」は、「つかった」の選択肢には出さない。貯金は「貯金へ入れた」で記録する(同じことを 2 通りで記録しないため)。
- 日付は、今日が自動で入る。押すとカレンダーが開き、過去の日付に直せる。未来の日付は選べない。
- 金額は、数字のキーボードを出す。0 円や空は、「金がくを 入れてね」と文字で伝える。
- さいふより多い金額を「つかった」「貯金へ入れた」にしようとしたら、「さいふより 多いよ。それでも きろくする?」と確認を出す(エラーにはしない。お金は借りることもあるため)。

### S5 きろくの一覧

```
│ きろく                  [11月 ▼] │
│ 11/13  🐷 貯金へ入れた    300円 │
│ 11/12  −  おやつ          100円 │
│ 11/12  ＋  おこづかい      500円 │
```

- 1 件を押すと、「直す」「消す」の選択が出る。「消す」を押したら、「ほんとうに 消す?」と確認を出す(元に戻せないため)。
- 色だけでなく、記号(＋ − 🐷 👛)と文字で、種類を伝える。

### S6 月のまとめ

```
│ ◀  2026年 11月  ▶          │
│ ＋ もらった 500円            │
│     おこづかい 500円 / お年玉 0円 │
│ − つかった 100円            │
│ 🐷 貯金へ入れた 300円          │
│                             │
│ つかった しゅるい別           │
│  おやつ    ■■■■■■  100円   │
```

- 項目ごとの合計は、横の棒(長さ + 数字 + 項目の色)で表す。グラフ用の道具は使わず、HTML と CSS だけで作る(最小版のため)。

### S7 ほしいもの

- カードを最大 3 枚。1 枚ごとに、名前、ほしい金がく、貯金の計画、進み具合の棒を出す。
- 貯金の計画: 「お年玉から ○円」「毎月のおこづかいから ○円」の 2 つの入力欄。どちらも、空でもよい。
- 「あと ○か月くらい」は、毎月の計画の金額から計算する(計画が空のときは、出さない)。
- 3 枚あるときは、追加のボタンを出さず、「ほしいものは 3 つまでだよ」と文字で伝える。
- 進み具合は、**貯金の合計 ÷ ほしい金がく**。ほしいものが複数あるときの分け方は、最小版では、いちばん上のものから順に貯金をあてる(順番は、作った順)。

### S8 しゅるい(項目)

- はじめから入っている「おやつ」「おもちゃ」「その他」は、直せない・消せない。自分で作ったものは、名前と色を直せる、消せる。
- 色は、あらかじめ用意した 8 色から選ぶ(自由な色にすると、読みにくい色を選べるため)。
- 消すとき、使われている記録があれば、「この しゅるいの きろくは『その他』に なるよ」と伝えて、確認を出す。

### S1 とうろく / S2 ログイン / S9 せってい
- S1 の入力欄: ニックネーム、パスワード(2 回)、👛 さいふ(いま、さいふに 入っているお金)、🐷 貯金(いま、貯金箱に 入れているお金)。説明は、この S1 でだけ、小さい文字で一度つける。ほかの画面は、絵と短い言葉だけにする。ニックネームには、「本名は 入れないでね」と注意を書く。
- S2 の入力欄: ニックネーム、パスワード。まちがえたときは、「ニックネームか パスワードが ちがうよ」と、どちらが違うかは教えない。
- S9: いま持っているお金と、いまの貯金の金額を直せる。ログアウトのボタン。

## 5. 見た目の決まり

| 項目 | 決まり |
|---|---|
| 背景 | クリーム色 `#FFF8E7` |
| 文字 | 濃い茶色 `#3B2F2F`(背景とのコントラスト比は 4.5:1 以上。実装のときに計算して確かめる) |
| さいふのカード | 淡い黄 `#FFE9A8` |
| 貯金のカード | 淡い緑 `#CDEBC5` |
| もらった | 淡い青 `#CFE3F7`(＋の記号つき) |
| つかった | 淡い赤 `#F8D0CC`(−の記号つき) |
| 文字の大きさ | 本文 18px 以上、見出し 24px 以上。太さは、本文 600、見出し 800 |
| 押せる部品 | 44px 以上。ボタンは、角を丸くして、文字を大きく太く |
| 動き | 最小限にする。点滅や、急な動きは使わない |

上の色は、できあがりを見て変えてよい(要件定義書 9-10)。色の値は、1 か所(CSS の変数)にまとめて、あとで変えやすくする。

## 6. 決めたこと・まだ決めないこと

**この案で決めたこと**
- 画面は 9 枚。下のタブは 5 つ。
- 「貯金へ入れた」と「貯金からだした」を、記録の種類として分ける。
- 色は、あらかじめ用意した 8 色から選ぶ。

**まだ決めないこと(実装のときに決める)**
- さいふと貯金の合計を、ホームに出すか(今は出さない)。
- ほしいものを「買えた」にしたときの動き(将来 KM-22)。
- パスワードを忘れたときの復旧(最小版では行わない)。
